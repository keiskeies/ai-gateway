# 概览监控大屏 · 设计方案（v2）

> 定位：Quiet Analytics + Wall Display。默认窗口下是「优雅的数据面板」，点击「全屏模式」切换为「监控墙」。
> 与上一版（霓虹亮片）的根本区别：单一强调色、靠明度分层而非发光、大字号等宽数字、克制的微动效。

---

## 1. 设计原则

1. **克制**：整页强调色只有一个（Mantine blue `#4c8dff` 系），状态语义色仅 3 个（绿/琥珀/红）。禁止多彩霓虹、禁止 `text-shadow` 辉光。
2. **层级靠明度**：背景分 3 阶明度（页底 → 面板 → 面板内卡片），不靠投影（阴影近乎为零）。
3. **数字是大屏灵魂**：KPI 用超大号 `tabular-nums` 等宽数字；所有数字（坐标轴、tooltip、排行）一律等宽对齐。
4. **一套调色全局一致**：模型固定 6 色调色板，趋势图 / 排行榜 / 环形占比共用——「一个模型 = 一个颜色」贯穿全页。
5. **微动效而非炫技**：刷新数字 300ms 过渡、环形仪表填充动画、呼吸灯、图表 500ms 重绘。所有动效时长 300–600ms。

## 2. 视觉 Token

### 2.1 背景与面板（暗色优先，亮色可切换）

| 角色 | 暗色值 | 用途 |
|---|---|---|
| `--wall-bg` | `#0B1120` | 页底（全屏模式压到 `#070B16`） |
| `--panel-bg` | `#111A2E` | 面板背景 |
| `--panel-bg-2` | `#182441` | 面板内卡片/悬浮层 |
| `--line` | `rgba(255,255,255,0.06)` | 1px 分隔/边框 |
| `--text-1` | `#F4F6FB` | 主数字/标题 |
| `--text-2` | `rgba(235,240,250,0.6)` | 次要文字/标签 |
| `--text-3` | `rgba(235,240,250,0.4)` | 辅助说明 |
| `--accent` | `#4C8DFF` | 单一强调色 |
| `--ok` / `--warn` / `--err` | `#2ECC8F` / `#FFB020` / `#FF5C5C` | 状态语义色 |

> 全屏模式下：`--wall-bg` 再压暗一档、面板边框更淡、字号整体 ×1.2、间距加宽，强化投屏观感。

### 2.2 字号阶梯（全部 `tabular-nums`）

| 级别 | 字号 / 字重 | 用途 |
|---|---|---|
| KPI 数字 | 44 / 700（全屏 52） | 核心指标 |
| KPI 单位 | 14 / 500 灰 | 数字下标单位 |
| 面板标题 | 13 / 600 + 字距 + 左侧 3px 强调竖条 | 各分区 |
| 图表轴/图例 | 11 / 400 | 坐标、legend |
| 正文/辅助 | 12 / 400 灰 | 说明文字 |

### 2.3 模型调色板（固定 6 色，全页一致）

```
['#4C8DFF', '#22D3EE', '#A855F7', '#2ECC8F', '#FFB020', '#F06595']
```

### 2.4 微动效

| 元素 | 动效 | 时长 |
|---|---|---|
| KPI 数字 | 刷新时计数过渡 | 300ms ease-out |
| 成功率环形 | `stroke-dasharray` 填充到目标 | 600ms |
| 并发呼吸灯 | `active_connections>0` 时小圆点 2s 呼吸 | loop |
| 图表 | 切换粒度/指标重绘 | 500ms |
| 面板 hover | 边框提亮 + 上移 1px（无投影、无发光） | 200ms |

## 3. 版式（默认窗口，1280+ 宽）

从上到下 4 个分区，间距 12px：

### 3.1 页头（56px）
- 左：`AI Gateway · 监控大屏`（16/700）+ 当前时钟（灰）
- 右：`自动刷新 [ON/OFF]` 开关（默认 30s）· `⏸ 暂停` · `⛶ 全屏` 三个 ghost icon 按钮
- 底部 1px `--line` 分隔

### 3.2 KPI 行（6 张，1 行 6 列；窗口窄自动折 3×2 / 2×3）
每张：左上 3px 强调竖条 + 右上 40px 半透明水印图标 + 大号数字 + 单位 + 右上角 delta 徽章（`↑3.2%` 绿 / `↓1.1%` 红，与上一周期比）。

| # | KPI | 主数字 | 内嵌微件 |
|---|---|---|---|
| 1 | 总请求 | `total_requests` | 60px sparkline（近 N 期） |
| 2 | 成功率 | `success_rate` | 80px 环形仪表（按状态色） |
| 3 | 平均延迟 | `avg_latency_ms` | sparkline + `ms` 单位 |
| 4 | 总 Token | `token_in + out` | 输入/输出**双色堆叠条**（纯灰底+实色，不发光） |
| 5 | 并发连接 | `active_connections`（后端需补） | 呼吸灯 |
| 6 | 活跃代理 | `activeProxies/total` | 灰底小胶囊 |

> 注：`OverviewStats` 目前**没有** `active_connections` 与「与上期对比」字段。
> 第 5 项并发、各 KPI 的 delta/sparkline 需要后端在 overview 里补 3 个字段（见 §6），属轻量增量。

### 3.3 主区（高度 ~440px，左右 3:2）
- **左（占 3/5）：模型请求趋势**
  - 堆叠/分组面积图（沿用现有 `SegmentedControl` 切换 + 粒度 日/月/年 + 指标 请求/入Tok/出Tok）
  - 填充改柔和渐变（顶 30% → 底 0），细网格 `rgba(255,255,255,0.05)`，hover 十字线 + 毛玻璃 tooltip
  - X 轴按粒度自动抽稀（日=每 2 天、月=每 2 月、年=全显）
- **右（占 2/5）：模型排行 + 平台占比**
  - 上：模型 Top N 横向条（同调色板），hover 显示精确值，点击可定位到该平台
  - 下：平台分布**环形图**（中心总量），下方 8px 色点图例列表

### 3.4 底部一行：虚拟模型健康看板（紧凑瓦片，可横向滚动）
- 每个 proxy 一个 `min-width 148px` 瓦片：
  - 顶：模型名（monospace, 12/600）+ 状态色点（绿=正常/琥珀=降级/灰=无流量）
  - 中：请求数（18/700 等宽）
  - 底：`成功率 xx% · 延迟 xxxms`（11 灰）
- 无流量瓦片整体降为 60% 灰度；**不用彩色竖条**（去掉上一版的色条机制）

## 4. 全屏模式（`⛶` 按钮 / `requestFullscreen`）

- 触发后：`document.documentElement` 加 `.wall-fullscreen`
- 效果：背景压到 `#070B16`、隐藏 `AppShell` 侧栏与顶部 logo 行、KPI 字号 ×1.2、主区高度随视口弹性拉满、自动刷新默认开启
- 退出：`Esc` 或再点按钮，恢复常规窗口布局
- 布局不变（仍是 §3 的 4 分区），只放大字号 + 拉高主区 + 隐藏壳层 → 纯投屏观感

---

## 5. 响应式降级

| 视口 | KPI | 主区 | 底部瓦片 |
|---|---|---|---|
| ≥1440 | 6 一排 | 3:2 并排 | 横向一排 |
| 1280–1439 | 3×2 | 3:2 并排 | 横向滚动 |
| 768–1279 | 3×2 | 纵向堆叠 | 横向滚动 |
| <768 | 2×3 | 纵向堆叠 | 横向滚动 |

## 6. 后端轻量增量（3 字段，可选但建议）

在 `OverviewStats` 增加：
```
pub total_connections_active: i64        // 当前在途请求（来自 selector 计数器）
pub requests_prev_period: i64            // 上一同级周期请求数（算 KPI delta）
pub avg_latency_prev_period: f64         // 上一周期延迟（算 delta）
```
- 前端 KPI delta 徽章 = `(cur - prev) / prev`
- 并发呼吸灯 = `total_connections_active`
- 若不想动后端：第 5、6 个 KPI 退化为「活跃代理」与「总平台数」，delta 徽章隐藏——**纯前端也能落地**，大屏核心（KPI+趋势+排行+平台环+瓦片）不受影响。

---

## 7. 实施顺序（每步可独立验收）

1. **视觉基线**：`main.css` 加 `--wall-*` token 组 + `.wall-fullscreen`；`Dashboard.tsx` 引入统一 token 对象（替代散落的 `#22d3ee` 硬编码）
2. **KPI 区**：6 卡 + 大数字 + delta + sparkline + 环形仪表 + 双色条
3. **主趋势图**：柔和渐变 + 十字光标 + 毛玻璃 tooltip + X 轴抽稀
4. **侧栏**：模型排行横向条 + 平台环形 + 色点图例
5. **底部瓦片行**：健康看板（去色条、灰度降级）
6. **全屏 + 自动刷新 + 响应式**收尾

---

## 8. 与上一版的取舍

| 上一版（被否） | 本版 |
|---|---|
| 每卡一个霓虹色 + 顶部色条 + 外发光 | 单一蓝强调色，卡片无色条、零发光 |
| 左侧 3px 色条标状态 | 状态用「色点 + 灰度降级 + 胶囊」表达 |
| `text-shadow` 辉光数字 | 纯白/纯黑数字 + `tabular-nums` 等宽 |
| 随机 12 色图表 | 固定 6 色模型调色板，全页一致 |
| 堆满霓虹 = 亮片 | 明度分层 + 克制微动效 = 高级感 |
